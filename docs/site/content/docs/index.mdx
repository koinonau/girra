Girra is a desktop IDE for running multiple AI coding agents side by side. Every task gets its own git worktree, its own agent terminal, and its own browser tab — so you can fan out work across Claude Code, OpenCode, and Pi without stashing, branch-juggling, or losing flow.

## When to use Girra

- You want three agents trying the same bug in parallel and to pick the winner.
- You want to review AI-generated diffs seriously before you ship them.
- You already use Claude Code, OpenCode, or Pi and want one place to orchestrate them.
- You want agents to run remotely — over SSH, on a self-hosted Girra server, or in an on-demand VM — without giving up your IDE.

## Who it's for

Girra is designed for people who already write code for a living and want to use AI as leverage — not as a replacement. It assumes you read diffs, care about commits, and keep a worktree tidy. If you're looking for a no-code tool, Girra is not that.

## What Girra is not

- **Not a model.** Girra runs agents you already use — bring your own Claude or OpenCode subscription.
- **Not a git replacement.** Every worktree is a real git worktree. You can `cd` in and use plain git whenever you want.
- **Not a hosted VPS product.** Girra runs on your desktop by default. Remote compute uses machines and cloud accounts you control — [SSH targets](/docs/ssh), [self-hosted Girra servers](/docs/remote-servers), or [Cloud VMs / per-workspace environments](/docs/ways-to-run#4-cloud-vms-per-workspace-environments).
